# DIME: Denoiser Ideal Membership Error

Code to reproduce the results in our DIME paper. Given a diffusion
model checkpoint, this repo evaluates membership inference attacks
(including DIME, our method) against it, matching the tables and figures
in the paper.

## 1. Setup

Two isolated environments are required: one for everything except DP-SGD
training, and a second used only for DP-SGD training (kept separate to
avoid a dual-cuDNN conflict introduced by `opacus`).

```bash
python -m venv venv-mia
source venv-mia/bin/activate
pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cu121

python -m venv venv-mia-dpsgd
source venv-mia-dpsgd/bin/activate
pip install -r requirements-dpsgd.txt --extra-index-url https://download.pytorch.org/whl/cu124
```

## 2. Getting model checkpoints

| Dataset | Source | How to obtain |
|---|---|---|
| CIFAR-10, CIFAR-100 | SecMI (Duan et al., ICML 2023) | Clone [jinhaoduan/SecMI](https://github.com/jinhaoduan/SecMI) and follow their README's checkpoint download link. Place the resulting files as `checkpoints/secmi_cifar10.pt`, `checkpoints/secmi_cifar100.pt`. |
| ImageNet-1k (Guided Diffusion) | OpenAI, class-conditional | Download `256x256_diffusion.pt` from the links in [openai/guided-diffusion](https://github.com/openai/guided-diffusion)'s README. Place at `models/256x256_diffusion.pt`. |
| STL10-U | Trained by us | No public checkpoint -- train from scratch, see Section 4 below. |
| CelebA (vanilla + DP-SGD) | Trained by us | No public checkpoint -- train from scratch, see Section 4 below. |

## 3. Data

Standard datasets (CIFAR-10, CIFAR-100, STL10, CelebA) are downloaded
automatically by `torchvision` on first use via `data.py`; point
`--data_root` at wherever you want them cached.

**ImageNet-1k and ImageNetV2** are not auto-downloaded. Obtain ImageNet-1k
through the standard ILSVRC access process, and ImageNetV2 from
[modestyachts/ImageNetV2](https://github.com/modestyachts/ImageNetV2).
Point `--imagenet1k_root` / `--imagenetv2_root` at their locations.

**CelebA (main table) and STL10-U both use a plain, naive random
member/held-out split**, generated by `make_split.py`:

```bash
python make_split.py --dataset stl10u --out_path ./data/stl10u_split.npz
python make_split.py --dataset celeba --out_path ./data/celeba_split.npz
```

By default this uses **SimA's stated split sizes** (50,000 for STL10-U,
30,000 for CelebA) rather than half of each dataset's total size --
important for CelebA specifically, since its true training split
(162,770 images) is far larger than SimA's 30k/30k convention, so relying
on an automatic `n_total // 2` default would silently produce the wrong
split size. Override with `--n_member` if you need a different size.

For CIFAR-10/CIFAR-100, use the member split files provided directly by
SecMI's repo (`member_split.npz`, `cifar100_split.npz`) rather than
regenerating your own.

**The identity-aware, capped CelebA split is used only for the DP-SGD
defense section (Section 7)** -- see the command there. Do not use it for
the main results table, and do not use the naive split above for the
DP-SGD section; they answer different questions and are not
interchangeable.

## 4. Training checkpoints from scratch

### Main results table (STL10-U, CelebA)

```bash
source venv-mia/bin/activate

python train.py --data_root ./data --dataset stl10u \
    --split_path ./data/stl10u_split.npz \
    --logdir ./logs/stl10u_ddpm --batch_size 128 \
    --lr 2e-4 --warmup 5000 --grad_clip 1.0 --ema_decay 0.999 \
    --total_steps 320000 --ckpt_every 20000 --sample_every 20000

python train.py --data_root ./data --dataset celeba \
    --split_path ./data/celeba_split.npz \
    --logdir ./logs/celeba_ddpm --batch_size 128 \
    --lr 2e-4 --warmup 5000 --grad_clip 1.0 --ema_decay 0.999 \
    --total_steps 320000 --ckpt_every 20000 --sample_every 20000
```

### DP-SGD defense section (Section 7 only)

These checkpoints use a *different* CelebA split (identity-aware, capped
-- see Section 7) and are not part of the main results table.

```bash
source venv-mia/bin/activate

python train.py --data_root ./data --dataset celeba \
    --split_path ./data/celeba_split_n1000_identity_aware_capped.npz \
    --logdir ./logs/celeba_ddpm_nondp_n1000 --batch_size 32 \
    --lr 2e-4 --warmup 5000 --grad_clip 1.0 --ema_decay 0.999 \
    --total_steps 15625 --ckpt_every 4000 --sample_every 4000
```

For DP-SGD checkpoints, switch environments (opacus is isolated):

```bash
source venv-mia-dpsgd/bin/activate

python train_dpsgd.py --data_root ./data --dataset celeba \
    --split_path ./data/celeba_split_n1000_identity_aware_capped.npz \
    --logdir ./logs/celeba_ddpm_dpsgd_eps1_n1000 \
    --target_epsilon 1.0 --epochs 500 --batch_size 32 --max_physical_batch_size 32 \
    --ckpt_every_epochs 100
# repeat with --target_epsilon 4.0 and 10.0 for the other privacy budgets
```

## 5. Running DIME

```bash
source venv-mia/bin/activate

python evaluate_dime.py \
    --checkpoint checkpoints/secmi_cifar10.pt --dataset cifar10 \
    --data_root ./data --split_path ./data/member_split.npz \
    --n_calib 500 --n_eval 12500 \
    --q_ref_grid 1 10 30 --batch_size 128
```

For ImageNet-1k / Guided Diffusion (class-conditional):

```bash
python evaluate_dime_imagenet.py \
    --checkpoint models/256x256_diffusion.pt \
    --imagenet1k_root /path/to/imagenet1k \
    --imagenetv2_root /path/to/imagenetv2 \
    --n_per_class 3 --q_ref_grid 1 10 30 --batch_size 24
```

This prints Level, Combined, and M results per `q_ref` tier; **Combined is
the method reported as DIME in the paper.**

## 7. Reproducing the DP-SGD defense table

Generate the identity-aware, capped split used only in this section (see
Section 3 for why this differs from the main table's split):

```bash
source venv-mia/bin/activate

python make_split_celeba_identity_aware_capped.py \
    --n_member 1000 --max_per_identity 2 \
    --out_path ./data/celeba_split_n1000_identity_aware_capped.npz
```

Then, after training all four checkpoints (Section 4), run
`evaluate_dime.py` and `baselines/evaluate.py` against each:

```bash
for CKPT_DIR in celeba_ddpm_nondp_n1000 celeba_ddpm_dpsgd_eps1_n1000 \
                celeba_ddpm_dpsgd_eps4_n1000 celeba_ddpm_dpsgd_eps10_n1000; do
    python evaluate_dime.py \
        --checkpoint logs/${CKPT_DIR}/ckpts/latest.pt \
        --dataset celeba --data_root ./data \
        --split_path ./data/celeba_split_n1000_identity_aware_capped.npz \
        --n_calib 500 --n_eval 500 --q_ref_grid 1 10 30 --batch_size 32
done
```

## Notes on reproducibility

- Every evaluation script accepts `--seed`; results in the paper use the
  default unless otherwise noted in the corresponding table caption.
- `--t_grid` and `--gamma_grid` defaults differ between the DDPM and
  ImageNet evaluation scripts (ImageNet's calibration region is centered
  at lower $t$) -- see each script's `--help` for the exact defaults used.
- Total DIME query cost per image is `q_ref + 1` (one shared base query,
  plus `q_ref` perturbed queries), reported as `#Query` in all tables.
